# FenneQ

**FenneQ** is Qamia's agentic coding platform that brings AI-assisted development right into your VS Code editor. FenneQ can plan complex tasks, edit files, run commands, and execute tests—all while you maintain full control.

Based on [Cline (Apache-2.0)](https://github.com/cline/cline).

## Features

- **Agentic Planning**: FenneQ analyzes your request, explores your code, and presents a clear plan before making changes
- **File Editing**: Create and edit files with diffs, monitors linter/compiler errors, and proactively fixes issues
- **Command Execution**: Run terminal commands with direct output feedback
- **Browser Automation**: Launch a browser, click, type, scroll, and capture screenshots for testing and debugging
- **MCP Support**: Extend FenneQ with custom tools via the Model Context Protocol
- **Full Control**: Review all plans and diffs, approve changes before they happen
- **Multi-Model Support**: Connect to Anthropic Claude, OpenAI, Google Gemini, AWS Bedrock, and other providers

## Getting Started

1. Install FenneQ from the VS Code Marketplace
2. Add your API keys for your preferred LLM provider
3. Open the FenneQ sidebar and start a task
4. Review FenneQ's plans and approve changes before they're applied
