# Solar, Aurora & Comet — Pick the Right Power

**FenneQ Cloud gives you three model tiers. Choose one per task in the model selector** (bottom of the chat, or Settings → API Configuration → FenneQ tier).

- **Solar** — Claude Opus 4.8. Frontier reasoning for the hardest problems: deep refactors, tricky debugging, architecture.
- **Aurora** — Claude Sonnet 4.6. The balanced everyday default — great for most coding.
- **Comet** — Claude Haiku 4.5. Fast and low-cost for quick edits, boilerplate, and high-volume work.

**Start on Aurora.** Drop to **Comet** to save cost on simple work; reach for **Solar** when a task is genuinely hard and you want the best reasoning.

No API keys to manage — **FenneQ Cloud** handles the model and billing for you.

> **Tip:** for agentic tasks (where FenneQ edits files and runs commands), keep **Adaptive Thinking off** so tool use stays reliable.
