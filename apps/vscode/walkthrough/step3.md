# Suhail, Altair & Mirzam — Pick the Right Power

**FenneQ gives you three model tiers. Choose one per task in the model selector** (bottom of the chat, or Settings → API Configuration → FenneQ tier).

- **Suhail** — Claude Opus 4.8. Named for the navigator's star: frontier reasoning for the hardest problems — tricky formulations, solver debugging, model architecture.
- **Altair** — Claude Sonnet 4.6. The flying eagle: the balanced everyday default — great for most modeling and solver work.
- **Mirzam** — Claude Haiku 4.5. The herald that rises first: fast and low-cost for quick edits, data wrangling, and high-volume work.

**Start on Altair.** Drop to **Mirzam** to save cost on simple work; reach for **Suhail** when a task is genuinely hard and you want the best reasoning.

All tiers run on **your Qortex key** — the subscription key from the Qortex portal that you entered at first launch, with per-task cost shown in the chat. Prefer another engine? The provider list also includes **Moonshot (Kimi K3)** and more, with your own API key.

> **Tip:** for agentic tasks (where FenneQ edits files and runs commands), keep **Adaptive Thinking off** so tool use stays reliable.
